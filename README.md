# Quantum Load Balancing for HPC Clusters

QAOA for 2-way HPC job scheduling, simulated at scale with NVIDIA CUDA-Q (statevector,
CPU and GPU), benchmarked against classical baselines. SC4055 group project; see
`PROJECT_PLAN.md` for the full formulation, roles, and experiment table, and `report/`
for the write-up.

## Setup

```
pip install -r requirements.txt
```

`cudaq` does not install on Apple Silicon (ARM macOS) — everything in `src/baselines.py`,
`src/problem.py`, and the classical-only experiments (E3, lambda sweep) runs fine without
it. Anything that imports `src/qaoa.py` (E1, E2, E4, E5, E6) needs a Linux machine with
`cudaq` installed (Colab/Kaggle GPU runtime, or a cluster like ASPIRE2A). `tests/test_qaoa.py`
skips itself automatically when `cudaq` isn't importable.

## Layout

```
src/
  problem.py      instances, Hamiltonian, cost, brute-force, metrics      (P2)
  qaoa.py         QAOA kernel, optimise, sample                          (P1)
  baselines.py    Karmarkar-Karp, greedy LPT, SA, CP-SAT                 (P3)
  bench.py        CSV logging, checkpointing, target switching           (P3)
experiments/      one script per experiment (E1-E6), plus make_figures.py
results/          CSVs each experiment script writes/checkpoints to
figures/          PNGs; always regenerated by make_figures.py, never hand-edited
cluster/          SLURM batch scripts for GPU runs
report/           LaTeX source
tests/            pytest; mirrors src/ one file each
```

## Reproducing every figure

Each experiment script checkpoints to its own CSV under `results/` and can be re-run
safely (it skips rows already on disk). `make_figures.py` only reads those CSVs — it
never calls `cudaq` itself — so figures can always be rebuilt on a laptop once the CSVs
exist.

| Figure(s) | Data from | Command |
|---|---|---|
| `baseline_approx_ratio.png`, `baseline_wall_time.png`, `baseline_violations.png` | `results/baselines_timing.csv` | `python experiments/E3_baselines.py` |
| `lambda_sweep.png` | `results/lambda_sweep.csv` | `python experiments/lambda_sweep.py` |
| `E1_approx_ratio.png`, `E1_p_opt.png` | `results/E1_depth.csv` | `python experiments/E1_depth.py --sizes 8 10 12` (CPU) and `python experiments/E1_depth.py --sizes 14 16 18 20 --target nvidia` (GPU) |
| `qaoa_vs_baselines.png` | the two rows above together | (no extra command — combines E1 + E3) |
| `E4_timing.png` | `results/E4_cluster/*/E4_timing.csv` | `python experiments/E4_timing.py --target qpp-cpu`, `... --target nvidia`, `... --target nvidia-fp64` |
| `E5_largen.png` | `results/E5_cluster/E5_largen.csv` | `python experiments/E5_largen.py` |
| `E2_init.png` | `results/E2/E2_init.csv` | `python experiments/E2_init.py` |
| `E6_noise.png` | `results/E6/E6_noise.csv` | `python experiments/E6_noise.py` |

Then, always:

```
python experiments/make_figures.py
```

which writes every figure its inputs currently allow to `figures/`.

## Seeds

Every instance is generated by `problem.generate_instance(n, seed)` — a `numpy`
`default_rng(seed)` is the only source of randomness anywhere in `src/` or `experiments/`
(no unseeded `np.random`, no wall-clock seeding), so every run in the table above is
exactly reproducible from the seeds each script already passes.
